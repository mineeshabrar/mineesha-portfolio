# Mineesha Brar — Portfolio

A personal, single-page portfolio based on Mineesha's resume. It shares her
backend engineering experience at PhonePe and JPMorganChase, a side project,
technical skills, and education in a simple editorial style. It includes a
link to Mineesha's LeetCode profile and a customizable cover letter. Its
personal visual style uses clean sans-serif typography and a calm sage palette.
It is plain HTML, CSS, and JavaScript, with no build step or package dependencies.

## Preview locally

Open `index.html` in a browser. Enter a role and company to personalize the
cover letter; use **Copy letter** to copy its text or **Print / Save PDF** to
print just the letter. Update `index.html` when experience, dates, or contact
details change.

## Publish with GitHub Pages

The public
[`mineesha-portfolio`](https://github.com/mineeshabrar/mineesha-portfolio)
repository publishes this site from the `main` branch root using GitHub Pages.
The live portfolio is at <https://mineeshabrar.github.io/mineesha-portfolio/>.

To make future changes, edit the site files in this folder, copy them to the
repository root, and push the changes to `main`. GitHub Pages will deploy the
updated site.
