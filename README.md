# Mineesha Brar — Portfolio

A personal, single-page portfolio based on Mineesha's resume, highlighting
her backend engineering experience at PhonePe and JPMorganChase, skills,
education, and two projects: a local-first, source-citing AI knowledge
assistant and a Go/Kafka notification producer-consumer demo. It includes
links to her professional profiles and separate contact options for recruiters
and people seeking guidance (the contact section is currently commented out
in the HTML). The personal visual style uses clean sans-serif typography and
a calm sage palette. It is plain HTML, CSS, and JavaScript, with no build step
or package dependencies.

## Preview locally

Open `index.html` in a browser. Email and profile links are available in the
header and footer. To restore the recruiter and guidance contact cards, remove
the HTML comment around the contact section in `index.html`. Update that file
when experience, dates, or contact details change.

## Publish with GitHub Pages

The public
[`mineesha-portfolio`](https://github.com/mineeshabrar/mineesha-portfolio)
repository publishes this site from the `main` branch root using GitHub Pages.
The live portfolio is at <https://mineeshabrar.github.io/mineesha-portfolio/>.

To make future changes, edit the site files in this folder, copy them to the
repository root, and push the changes to `main`. GitHub Pages will deploy the
updated site.
